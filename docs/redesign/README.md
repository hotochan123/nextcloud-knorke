# Redesign 2026-10

Entwurf aus der OpenDesign-Runde vom 29.10.2026. Er wird in den Backlog-Zeilen „Redesign …“ umgesetzt (grill-me `redesign-umsetzung`).

- `index.html`: Prototyp mit den Ansichten P1–P12, im Browser öffnen; Deep-Links wie `index.html#P7`.
- `tokens.css`: Farben, Abstände, Radien, Ebenen, Schrift.
- `zuordnung.md`: jedes Bedienelement von heute mit seinem neuen Ort.
- `UEBERGABE.md`: der Auftrag an OpenDesign mit den Vorschlägen V1–V17; Entscheidungen in Abschnitt 10.
- `heute-tokens.css` und `screenshots/`: der Stand vor dem Redesign.

Dunkelmodus nur in Variante (b): Die Leinwand bleibt hell, die Leisten werden dunkelgrau. Variante (a) im Prototyp gilt nicht.

Wo eine Backlog-Zeile vom Entwurf abweicht, gilt die Zeile. Abweichungen gibt es zum Beispiel bei den alten Palettenfarben, bei der Notiz-Textgröße bestehender Notizen, beim Frame-Namen über dem Frame und bei Arial auf der Leinwand.
